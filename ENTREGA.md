# Checklist de entrega - CP4

## O que deve ser enviado no Teams

Apenas um integrante do grupo deve enviar estes tres arquivos:

1. `video1_reidentificado.mp4`
2. `video2_reidentificado.mp4`
3. `Relatorio_CP4.pdf`

Os arquivos prontos estao na pasta `entrega/` do pacote completo.

## Validacao das regras do enunciado

| Regra | Situacao |
| --- | --- |
| Trabalho individual ou grupo de ate 5 alunos | Conforme: grupo com 5 integrantes |
| Somente um integrante realiza a entrega | Acao necessaria: escolher um integrante para enviar |
| Um MP4 processado para cada video fornecido | Conforme: foram gerados 2 MP4 |
| Exibir a caixa da pessoa reidentificada | Conforme: caixa vermelha e valor de similaridade |
| Testar cor, orientacao e combinacao | Conforme: 3 metodos e 66 configuracoes avaliadas |
| Buscar a melhor confianca minima | Conforme: 4 confiancas YOLO avaliadas |
| Entregar relatorio simples com analise | Conforme: `Relatorio_CP4.pdf` |
| Entrega pelo Teams, na aba Tarefas | Acao necessaria pelo integrante responsavel |
| Realizacao presencial em 03/09/2026, no horario da aula | Regra administrativa que deve ser confirmada pelo grupo |
